# PWEB Práctica 4 - Galería de Ariana Grande

Este repositorio contiene una galería de imágenes de Ariana Grande creada para la Práctica 4 de Programación Web.

## Contenido del Repositorio

- `index.html` - Página HTML con galería de imágenes (con CSS embebido)
- `image_1.jpg` - `image_6.jpg` - Imágenes de la galería (formato JPG y PNG)

## Migración a programacion_web_final

Este contenido debe ser migrado al repositorio: https://github.com/alainsillo/programacion_web_final.git

### Instrucciones de Migración

Ver `MIGRATION_GUIDE.md` para instrucciones detalladas sobre cómo migrar este contenido al repositorio final.

También está disponible el script `migrate_to_final.sh` para automatizar el proceso de copia.

## Características de la Galería

- Diseño responsivo con Flexbox
- Efectos hover con transformaciones CSS
- 6 imágenes organizadas en una cuadrícula
- Estilos personalizados con tema rosa
